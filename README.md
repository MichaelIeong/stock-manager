# my-stocks

個人投資組合分析工作區，AI 輔助追蹤美股、港股、A 股持倉與觀察清單。

## 內容

| 檔案 | 說明 |
|---|---|
| `positions.md` | 持倉紀錄（標的／數量／成本價／結構） |
| `watchlist.md` | 觀察清單（美股 + 港股 + A 股） |
| `plan.md` | 新增資金配置計劃 |
| `DATA/` | 每日即時報價快照存檔 |
| `memory/` | 分析日誌與長期記憶 |

## 使用方式

搭配支援 AGENTS.md 的 AI 工具打開此工作區，對 AI 說「分析我的持倉」即可獲得即時報價、當天新聞與風險分析。

## 備註

- 所有報價數據均來自公開來源（CNBC 開放 API），無需登入或 API key
- 不執行任何交易操作，僅供分析參考
